One kind, funny fortune for a houseplant, written as if told to the plant in its pot on the sunny windowsill: its roots are about to outgrow the pot, and its keeper is finally going to buy it a bigger one. Pure Python standard library — no dependencies, no network, fully deterministic. The program writes the single fortune line to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`), enforcing the competition's gates first: 1–120 characters, one line, UTF-8, non-blank, no control characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
